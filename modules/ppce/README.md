# PPCE — banco editorial de questões

Este módulo contém questões autorais para o concurso de Policial Penal do Ceará.
As questões serão organizadas por disciplina e vinculadas à taxonomia SQL existente:
`disciplina → assunto → tópico → subtópico`.

O concurso não recebe banca no banco de dados. IDECAN e Cebraspe são apenas
referências editoriais de dificuldade e formato.

## Disciplinas
